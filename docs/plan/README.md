# The plan

This site is built from a written plan, step by step, and the plan is public. Read it in this order:

1. `00-scope.md` — what the site is for, the constraints, the priorities, and the decisions that shaped it.
2. `01-plan.md` — the stack, the routes with their budgets, the gates every pull request must clear, and the nine steps with their sign-off criteria.
3. `steps/PS-n.md` — one log per step: branch, pull request, which criteria passed and with what evidence, and when the step was signed off.
4. `../decisions.md` — the dated decision log.

Working notes, research reports and review passes are kept in a private working copy; nothing from them is needed to follow the plan. The private copy contains local file paths and third-party details that do not belong on a public site, which is why the public documents are written separately rather than copied.
